# Experiments

Use this directory for self-contained computational investigations that support
multiple notes or deserve an independent result record.

Each experiment should state:

- the question and falsifiable expectation;
- environment and reproducible command;
- configuration and seed policy;
- source and license of any data or model;
- expected and observed output;
- interpretation, limitations, and negative results;
- notes and research threads that depend on it.

Note-specific checks belong inside `notes/<slug>/code/` instead.
