# Research-unit template

Copy this entire folder for a new question-centered note.

- `research-note-template.md` is the intellectual spine. Rename it to the
  question slug after copying this folder.
- `code/` contains scripts or notebooks used only by this note.
- `figures/` contains explanatory or generated images.
- `data/research-note-template-data-guide.md` records provenance and retrieval
  instructions; rename it to match the question slug. Do not commit large,
  private, copyrighted, or redistributability-unclear data.
