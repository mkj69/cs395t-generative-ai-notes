# Notes

This directory is reserved for the author's original research notes.

It intentionally contains no downloaded lecture PDFs and no generated course
summaries. A new note should begin by copying the complete `_template/`
research-unit folder and become public only after its claims, citations,
experiments, and uncertainties have been reviewed.

Rename `research-note-template.md` to the question slug after copying. Logseq
requires every Markdown filename in this repository to be unique.
