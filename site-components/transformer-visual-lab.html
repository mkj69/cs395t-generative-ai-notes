current object token_ids: [T]

STEP 01 · LINEAR PROJECTIONS qᵢ = WQ xᵢ · kⱼ = WK xⱼ · vⱼ = WV xⱼ 
Q = X @ W_Q
K = X @ W_K
V = X @ W_V

Honesty note. This head is intentionally two-dimensional and hand designed so its arithmetic can be inspected. It explains the mechanism; it does not claim to reproduce a trained model's learned attention pattern.
