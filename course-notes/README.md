# Course learning notes

This directory contains lecture-ordered learning notes written by the author.

Learning notes are not research claims and are not generated summaries. They
record closed-source reconstruction, derivations, original examples, errors,
corrections, and unresolved questions. Copy `_template/` to begin a lecture.

Statuses:

- `capturing`: structure and questions are being collected;
- `reconstructing`: the author is explaining and deriving from memory;
- `checked`: the reconstruction has been checked against the lecture and
  sources actually read.

Downloaded PDFs do not belong here. Record a stable source URL instead.

See `MANUAL_NOTE_WORKFLOW.md` at the repository root for the full no-AI method.
